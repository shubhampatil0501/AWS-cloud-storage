AWS S3 File Manager & Cloud Storage Platform

A lightweight, modern web-based cloud storage interface inspired by AWS S3 and Google Drive. Designed with a clean glassmorphism UI, this application provides an intuitive frontend for managing cloud objects, searching files, and simulating seamless uploads and downloads.

Features

S3 Bucket Dashboard: View total storage consumption, active bucket metadata, and object counts.

Drag & Drop Uploads: Interactive drop zone with instant file handling and preview simulation.

Dynamic File Management: Clean tabular view showing file names, types, sizes, and upload dates.

Real-Time Search: Instantly filter files in your bucket as you type.

Action Suite: Download files or remove them from storage with custom toast notifications.

Modern UI/UX: Built with Tailwind CSS and styled with frosted glassmorphism elements, dark mode aesthetics, and AWS-themed orange accents.

Tech Stack

Frontend: HTML5, JavaScript (ES6+)

Styling: Tailwind CSS (via CDN)

Icons: Lucide Icons

Fonts: Inter (Google Fonts)

Getting Started

To run or inspect this project locally:

Clone your repository:

git clone https://github.com/shubhampatil0501/aws-cloud-storage-platform.git


Navigate into the project directory:

cd aws-cloud-storage-platform


Open index.html directly in your preferred web browser, or serve it using a local development server (e.g., Live Server in VS Code).
